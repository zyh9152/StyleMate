# StyleMate

StyleMate 是一个移动端穿搭推荐 Demo。用户依次选择场合、气温、行程、气质、配色和版型后，页面会生成一套完整的穿搭建议。

## 本地预览

直接使用浏览器打开 `index.html` 即可，无需安装依赖或启动服务器。

## 项目结构

```text
StyleMate/
├── index.html    # 页面结构
├── style.css     # 页面样式
├── app.js        # 交互与搭配生成逻辑
└── assets/       # 本地字体和图片
```

项目采用原生 HTML、CSS 和 JavaScript 开发，所有运行资源均保存在本地。
